# GrindValue: releases

GrindValue is a World of Warcraft addon for **WoW Forever**. It shows what mobs, gathering nodes, chests and fishing pools are worth, tracks your luck and best drops, draws heatmaps of where you earned your gold, and shares this data with your guild.

This repository holds **only the releases**. You get the download and the changelog for each version under [Releases](../../releases).

## Installation

1. Download `GrindValue-<version>.zip` from the latest release.
2. Unpack it into `World of Warcraft\_forever_\Interface\AddOns\` so that you get the folder `AddOns\GrindValue`.
3. Start the game or type `/reload`.

When a guildmate has a newer version, GrindValue shows a note in its dashboard with the link to that release.
